# שימוש ברשת הביתית

מסלול Windows זה מוסיף HTTPS מקומי ללא חשבון, דומיין או שירות מרכזי. הוא דורש חבילה משולבת הכוללת את שינויי האפליקציה והמתקין המפורטים ב־`evidence/lan-integration-manifest.json`. אין להפעיל מתקין ישן עם קובצי payload שהוחלפו ידנית.

בהתקנה חדשה אפשר להישאר עם שימוש במחשב הזה בלבד. כדי להצטרף מטלפון או מטאבלט בוחרים „גם ברשת הביתית”, בוחרים במפורש מתאם וכתובת פרטית, ומאשרים את התוכנית והפורטים המוצגים. אין זיהוי אוטומטי ודאי של VPN או של רשת ביתית. Windows חייב להגדיר את המתאם כרשת **Private**; המתקין אינו משנה את הסיווג.

האישור מאפשר ל־Caddy של ההתקנה לקבל TCP ב־443, וב־80 רק אם נבחר דף עזרה, בפרופיל Private ומהתת־רשת המקומית. כל כלל קשור גם לקובץ התוכנית ולכתובת שנבחרו. אין port forwarding, ‏UPnP, מנהרה או IPv6 ציבורי. רשת אורחים או בידוד בין מכשירים עשויים למנוע חיבור גם באותו Wi-Fi.

האפליקציה ממשיכה להאזין רק ל־127.0.0.1. פרוקסי נפרד מגיש HTTPS בכתובת הביתית, עם CA ייחודי להתקנה. המפתח הפרטי נשאר בספרייה מוגנת של זהות שירות נפרדת, ללא הרשאה לזהות האפליקציה. המתקין אינו מוסיף אמון בתעודה במחשב או בטאבלטים.

## הצטרפות ממכשיר נוסף

1. השאירו את המחשב פועל ופתחו במכשיר השני את כתובת דף העזרה שמופיעה במסך ההתקנה. הדף ב־HTTP מכיל רק הוראות ותעודה ציבורית; אין בו כניסה, שיחות או גישה ל־API.
2. הורידו את התעודה הציבורית. לחלופין, לחצו במחשב על „שמירת התעודה הציבורית” והעבירו אותה למכשיר בערוץ עצמאי שאתם סומכים עליו. QR אינו נדרש.
3. לפני אישור אמון, השוו את טביעת SHA-256 של התעודה למספר שמופיע **במסך המחשב המארח** או בתקשורת עצמאית מאומתת איתו. טביעה שמוצגת באותו דף HTTP אינה מוכיחה שהתעודה נכונה. אם המכשיר אינו מציג טביעה, בדקו את הקובץ במחשב המארח והעבירו את הקובץ שנבדק בערוץ עצמאי; אל תאשרו קובץ ממקור לא מאומת.
4. פעלו לפי הוראות מערכת ההפעלה בדף העזרה. ב־iPad/iPhone התקנת פרופיל לבדה אינה מפעילה אמון SSL: נדרשת גם הפעלת אמון בהגדרות התעודות. אין לדלג על אזהרת דפדפן.
5. פתחו את כתובת HTTPS, אשרו הרשאת מיקרופון אם דרושה והתחברו לחשבון יחד. בדקו בפועל כניסה, קובץ והקלטה במכשיר שבו תשתמשו.

דף העזרה אינו יכול לקרוא את חנות האמון במכשיר או להתקין אמון אוטומטית. גם בדיקת HTTPS מוצלחת במחשב אינה בדיקה מטאבלט. כשל בחיבור עשוי לנבוע מכתובת, שינה, רשת אורחים, שירות, firewall, תעודה או גורם אחר; הוא אינו אבחנה שחסרה תעודה.

## שינוי כתובת, שינה ותיקון

המחשב צריך להישאר פועל ומחובר. לאחר שינה, חזרה, שינוי DHCP או שינוי מתאם, השירות אינו עובר אוטומטית לכתובת אחרת. כשכתובת שנבחרה נעלמת הפרוקסי נעצר. פותחים שוב את אותו מתקין, בוחרים במפורש את הכתובת הביתית הנוכחית ומאשרים מחדש את הכללים. אפשר גם לשמור כתובת בנתב לפי הוראותיו; המתקין אינו משנה את הנתב.

בתיקון נשמר ה־CA של הבית. שינוי IP עשוי לדרוש תעודת שרת חדשה, אך אינו אמור להחליף את רשות התעודות שעליה כבר סומכים. אם חומר ה־CA פגום או הטביעה השתנתה, הגישה נעצרת ומוצג כשל. אין הנפקת זהות חדשה בשקט. אתחול ראשון שנקטע לפני שפורסמה תעודה יכול להמשיך באמצעות מנגנון האחסון של Caddy.

כשל חלקי משאיר רישומי הכנה/תצורה מוגנים. תיקון של רכיבים שטרם קיבלו רישום בעלות מלא דורש אותה בחירה מפורשת, או הסרה מאומתת של אותה התקנה. אין מחיקת שיחות, איפוס מפתחות משפחה או מעבר ל־HTTP כפתרון אוטומטי. כללים לא מוכרים או ששונו נשמרים ומדווחים, ואינם נדרסים.

## כיבוי והסרה

„כיבוי הגישה הביתית” עוצר את הפרוקסי, מבטל את הפעלתו האוטומטית ומסיר רק את הכללים התואמים לרישום ההתקנה. עבודה במחשב חוזרת ל־loopback. חומר ה־CA נשמר כדי שהפעלה מחדש לא תחליף זהות.

שתי בחירות ההסרה נשמרו: הסרה עם שמירת נתונים שומרת גם את חומר ה־CA; הסרה מלאה מוחקת גם אותו לאחר עצירת השירות ואימות הבעלות. החלטת המחיקה נשמרת מחוץ לתיקיות שנמחקות, כך שניסיון חוזר אינו יכול להפוך מחיקה מלאה לשמירה בטעות.

ההסרה מהמחשב אינה יכולה להסיר אמון שהותקן בטלפון או בטאבלט. הסירו בכל מכשיר את תעודת הבית המזוהה לפי הטביעה שמופיעה במסך ההסרה. ההוראות לכל מערכת נמצאות גם בדף העזרה. מחיקת קובץ ההורדה אינה מסירה אמון שכבר הותקן.

## גישה מהאינטרנט

זו הגדרה נפרדת שאינה מופעלת בהתקנה. ראו `docs/INTERNET-ACCESS.md` באפליקציה: Tailscale Serve פרטי הוא המסלול המועדף; Funnel הוא מסלול ציבורי עם השלכות ומגבלות אחרות. החשבון והתשתית הם של המשתמש. מדריך זה אינו מפעיל ספק. במתקין Native טרם קיימת הגדרת origin חיצוני מאושרת; אין לערוך את רישומי הבעלות המוגנים או לעקוף Origin/CSRF כדי להפעילו.

## מה נבדק

נבדקו תכנון Caddy באמצעות `adapt` ללא האזנה, בדיקות יחידה/שילוב סינתטיות, רינדור WPF ללא הצגת חלון, ו־Origin/cookies/CSRF באפליקציה עם mock. פירוט הראש המדויק והמספרים נמצא ב־manifest. לא בוצעו התקנה חיה, שינוי הרשאות/חומת אש/אמון, SCM אמיתי, בדיקת טאבלט, הקלטה פיזית או אימות אחרי reboot. מסלול Linux/Pi הקיים מתועד ב־`docs/INSTALL.md`; חיבור המתקין החדש במסמך זה הוא Windows בלבד.

מקורות: [Caddy local HTTPS](https://caddyserver.com/docs/automatic-https#local-https), [Caddy global options](https://caddyserver.com/docs/caddyfile/options), [Microsoft firewall rules](https://learn.microsoft.com/en-us/windows/win32/api/netfw/nn-netfw-inetfwrule), [Windows network category](https://learn.microsoft.com/en-us/windows/win32/api/netlistmgr/nf-netlistmgr-inetwork-getcategory), [Apple certificate trust](https://support.apple.com/en-us/102390).
