Native PLAN, CHECKPOINT, HANDOFF, dated acceptance and evidence reports describe
implementation stages. Their counts and machine observations are historical.
Current source, test entry points and validation status govern release decisions.
Historical references to raw artifacts identify the original run; logs, screenshots
and generated manifests are no longer carried in the source tree.
