# Historical validation reports

These written reports describe individual development stages, not current release
acceptance. Start with [validation status](../docs/VALIDATION.md) and the
[development guide](../docs/DEVELOPMENT.md).

Raw logs, screenshots, generated JSON and output are excluded from the current
source tree. Old reports may name those artifacts; earlier tracked versions remain
in Git history. New output belongs in ignored `.local/`. Keep useful written
findings with the source commit, scope and limitations.
