מחברים את המכשיר
למחשב המשפחתי

המכשיר והמחשב צריכים להיות מחוברים לאותה רשת ביתית. המחשב צריך להיות דלוק וער. אין צורך בחשבון חיצוני או במנוי.

1. קודם מנסים את הכתובת המאובטחת

__LAN_HTTPS_ORIGIN__ בדיקת חיבור HTTPS

אם יחד נפתחת בלי אזהרת אבטחה, אפשר להתחבר לחשבון שם. בדיקת הקישור בודקת חיבור בלבד; הדף הזה אינו יכול לקרוא את הגדרות האמון של המכשיר.

אם החיבור נכשל, זה לא מוכיח שחסרה תעודה. ייתכן שהמחשב ישן, כתובתו השתנתה, המכשירים ברשתות שונות או שיש חסימת רשת. רשת אורחים עשויה להפריד בין מכשירים.

מופיעה אזהרת דפדפן? אל תדלגו עליה. חזרו לכאן והיעזרו בשלבים הבאים.

2. מאמתים מול מסך המחשב המארח

התעודה מאפשרת למכשיר לזהות את המחשב של יחד ולהצפין את החיבור אליו. התקינו אותה רק לאחר שהשוויתם את טביעת האצבע של קובץ התעודה שהורדתם לזו שמוצגת במסך ההתקנה במחשב המארח, או בערוץ עצמאי שאתם סומכים עליו.

הדף הזה וההורדה נשלחים ב־HTTP. טביעת אצבע שמופיעה רק כאן אינה הוכחת אמינות. אל תאשרו אמון אם אין לכם את טביעת האצבע ממסך המחשב או אם הערכים אינם זהים.

אם המכשיר אינו מציג את טביעת SHA-256 ואין דרך אמינה לחשב אותה, אל תתקינו קובץ שהגיע רק מהדף הזה. אפשר להעביר את התעודה הציבורית ישירות מהמחשב המארח בכבל או בערוץ עצמאי מאומת.

טביעת SHA-256 המפורסמת כאן, לעזר בלבד:

__ROOT_SHA256__ הורדת התעודה הציבורית

זהו קובץ תעודה ציבורית בלבד. אין צורך להוריד מפתח פרטי. אישור תעודת שורש הוא שינוי אמון במכשיר; אשרו רק את התעודה הייחודית של ההתקנה שלכם.

3. מאשרים פעם אחת במכשיר הזה

בחרו את ההסבר למכשיר שלכם. שמות התפריטים משתנים בין גרסאות ויצרנים. אם המכשיר מנוהל או חוסם התקנת תעודות, פנו למי שמנהל אותו.

iPhone או iPad
  1. הורידו את התעודה. פתחו את הגדרות המכשיר ואת הפרופיל שהורד. לפני ההתקנה, פתחו את פרטי התעודה והשוו את SHA-256 למסך המחשב המארח.
  2. אם הערכים זהים, התקינו את פרופיל התעודה באמצעות הגדרות המכשיר.
  3. עברו אל כללי ← אודות ← הגדרות אמון בתעודות, והפעילו אמון מלא לתעודת השורש של יחד שאימתם.
  4. חזרו לקישור HTTPS למעלה. רק לאחר שנפתח ללא אזהרה מתחברים לחשבון ומאשרים מיקרופון, אם רוצים להקליט.
Android
  1. הורידו את התעודה ופתחו את פרטי הקובץ/התעודה. השוו את SHA-256 למסך המחשב המארח לפני שמאשרים אמון.
  2. בהגדרות, חפשו ״התקנת תעודה״ או ״אישור CA״. הנתיב בדרך כלל נמצא תחת אבטחה ופרטיות ← הגדרות אבטחה נוספות ← הצפנה ופרטי כניסה.
  3. בחרו התקנת אישור CA, בחרו את הקובץ שאימתם ואשרו לפי הנחיות המכשיר. ייתכן שתידרש נעילת מסך. אין צורך בתעודת משתמש או בתעודת Wi-Fi.
  4. פתחו שוב את קישור HTTPS בדפדפן. אם נשארת אזהרה, עצרו ובדקו את התאימות לדפדפן ולגרסת המכשיר.
Windows נוסף בבית
  1. שמרו את קובץ התעודה. כדי לחשב SHA-256 של הקובץ לפני הייבוא, פתחו PowerShell והשתמשו בפקודת Get-FileHash עם Algorithm SHA256 ונתיב הקובץ שהורדתם. השוו את התוצאה למסך המחשב המארח.
  2. רק אם הערכים זהים, פתחו את התעודה ובחרו ״התקנת אישור״ למשתמש הנוכחי, ואז את מאגר ״רשויות אישורים בסיסיות מהימנות״ (Trusted Root Certification Authorities).
  3. אשרו את אזהרת התקנת תעודת השורש שאימתם. זו פעולה בהגדרות מערכת ההפעלה; אין לדלג על אזהרת אתר בדפדפן.
  4. פתחו מחדש את קישור HTTPS. חלק מהדפדפנים מנהלים מאגר אמון נפרד; אם נשארת אזהרה יש לבדוק את הוראות הדפדפן.

הוראות אלה הן הדרכה להגדרה ידנית. הצלחה במחשב המארח אינה הוכחה שהמכשיר השני כבר סומך על התעודה.

אם הכתובת השתנתה או שמסירים את יחד

אחרי שינוי כתובת רשת, פתחו שוב את כלי ההתקנה במחשב המארח ובחרו את הרשת הנכונה. אל תאשרו תעודה חדשה בלי לאמת אותה מחדש מול המחשב.

בהסרת יחד מהמחשב, האמון שאישרתם בטאבלטים ובמכשירים אחרים אינו נמחק מרחוק. הסירו גם אותו: ב־iPhone/iPad דרך כללי ← VPN וניהול מכשיר והגדרות אמון בתעודות; ב־Android דרך אישורים מהימנים/אישורים שהותקנו; ב־Windows דרך ניהול אישורי המשתמש (certmgr.msc), במאגר רשויות בסיסיות מהימנות.

מחקו רק את התעודה של ההתקנה הזו, לפי טביעת האצבע שאימתם. אל תמחקו תעודות אחרות. ההחלטה לשמור או למחוק נתוני משפחה בהסרת התוכנה היא בחירה נפרדת.

זהו דף עזרה ציבורי ברשת הביתית בלבד. אין כאן כניסה לחשבון, שיחות או פרטי משפחה. הגישה דרך האינטרנט אינה מופעלת כאן.
